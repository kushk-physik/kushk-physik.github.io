# kushk-physik.github.io

Personal academic website of **Khwahish Kushwah**, theoretical physicist
(relativistic magnetohydrodynamics from kinetic theory, heavy-ion collisions, magnetized astrophysical plasmas).

Live at [kushk-physik.github.io](https://kushk-physik.github.io)

## Pages

- `index.html` — biography, recent news, featured science, more about me, collaborators
- `publications.html`, `cv.html`, `talks.html`
- `style.css` — shared styles · `main.js` — animated magnetic-field-line background and mobile menu
- `assets/img/` — figures from the papers

Plain HTML, CSS and JavaScript, served by GitHub Pages.

## Updating

- **News:** copy an `<article class="news">` block in `index.html`.
- **New paper:** add an `<article class="sci">` card under Featured Science (figure in `assets/img/`) and a line in `publications.html`.
- **New talk:** add an `<li>` at the top of the list in `talks.html`.
