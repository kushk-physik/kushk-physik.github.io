# kushk-physik.github.io

Personal academic website of **Khwahish Kushwah**, theoretical nuclear physicist
(relativistic magnetohydrodynamics from kinetic theory, heavy-ion collisions, magnetized astrophysical plasmas).

Live at [kushk-physik.github.io](https://kushk-physik.github.io)

## Structure

- `index.html` — all content (about, news, featured science, publications, talks, experience, collaborators)
- `style.css` — dark theme and layout
- `main.js` — animated magnetic-field-line hero, mobile menu, scroll effects
- `assets/img/` — figures from the papers

Plain HTML, CSS and JavaScript, served by GitHub Pages.

## Updating

- **News:** copy a `<article class="news-card">` block in the News section.
- **New paper:** add a `<a class="sci-card">` card in Featured Science (figure in `assets/img/`) and a line under Publications.
